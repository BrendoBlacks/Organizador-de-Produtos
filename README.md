# 📦 Organizador de Produtos

Sistema simples de **gerenciamento de produtos**, desenvolvido em Python para praticar lógica de programação e modularização.

## ⚙️ Funcionalidades

* ➕ Cadastrar produtos
* 📋 Listar produtos
* ✏️ Editar produtos
* 🗑️ Excluir produtos
* ✅ Validação de dados

## 🧠 Conceitos praticados

* Listas e dicionários
* Funções
* Estruturas condicionais e de repetição
* `try/except`
* Validação de dados
* Modularização

## ▶️ Como executar

```bash
git clone https://github.com/BrendoBlacks/Organizador-de-Produtos.git
cd Organizador-de-Produtos
python principal.py
```
